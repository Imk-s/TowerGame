基于 C++ 与 Qt 的 2D 塔防游戏 (Tower Defense)
​本项目是自学C++以来独立完成的首个完整软件工程项目。开发过程将ACM算法训练中的数据结构思维与面向对象（OOP）三大特性深度结合，实现了一个包含完整动态经济系统、图论寻路逻辑、以及基于MVC架构的数据/界面解耦的塔防游戏闭环。
​开发哲学
秉持“人机协同”的现代开发理念，最大化开发效率。本人主导项目核心逻辑、算法架构与数据流转，AI助手（Trae, Claude, Gemini）负责 UI 渲染引擎封装、状态机补全与底层 API 调用。
​ 核心架构与算法落地 
​本人独立负责的核心底层逻辑设计：
​OOP 多态系统设计：抽象提炼Enemy基类，派生三种特性敌人类（Monster, Hound, Tank），利用虚函数实现移动与承伤的多态重写。
​抽象提炼Tower基类，派生三种防御塔（Normal, Cannon, Light），并在塔类内部封装独立的子弹结构体与发射逻辑，实现对象间的独立解耦。
​图论寻路与 O(1) 移动机制 (核心亮点)：地图类与关卡类数据解耦。关卡构造函数初始化地图数据与刷怪事件后，交由 Map 类执行BFS（广度优先搜索）算法。
​将计算出的最短路径统一映射为点集队列，传输给敌人类的 move() 函数，将复杂的寻路过程完美降维成 O(1) 时间复杂度的节点移动机制。
​帧同步主循环引擎：在 Widget 核心类中构建基于定时器（Timer）的主循环引擎。
​每帧动态解析事件队列（波次刷怪），遍历并更新塔、敌人、子弹三大实体列表，实现精准的碰撞判定与数值结算。
​ 渲染与工程辅助 
​由 AI 完成的脏活/累活与视觉表现层代码：
​UI 渲染与视图转化 (Trae / Claude)：将后端的整型网格坐标系，通过算法转化为前端UI渲染所需的QPointF浮点像素坐标系。
​全面接管 paintEvent 绘制逻辑，包括开始界面、背景贴图拼接、防御塔/敌人精灵图渲染以及动态血条的UI映射。
​多媒体与状态机 (Trae / Claude)：搭建全局 UI 状态机，实现“主菜单-游戏中-胜利结算-失败结算”的场景无缝切换，并挂载BGM与开火音效。
​架构重构顾问 (Gemini 3.1 Pro)：在架构设计期提供依赖关系梳理，给予我清晰的架构思路与建议，协助解决 C++ 编译与Qt资源打包部署等工程化问题。
